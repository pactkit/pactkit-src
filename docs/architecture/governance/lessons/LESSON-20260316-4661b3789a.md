Multi-format deployment (classic/plugin/marketplace/opencode) reuses existing helpers (_deploy_skills, _deploy_agents, _deploy_commands) with different path prefixes via `skills_prefix` parameter — adding a new format requires: (1) constant in VALID_FORMATS, (2) path prefix constant, (3) routing in deploy(), (4) format-specific _deploy_X() function, (5) format-specific JSON config generator; path rewriting at write time keeps templates canonical
