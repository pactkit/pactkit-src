When the target tool lacks `@import` syntax (OpenCode vs Claude Code), use its native config mechanism (`opencode.json` `instructions: ["rules/*.md"]`) for modular rule loading instead of inlining everything into a single file; `_update_global_opencode_json()` with merge strategy preserves user-owned fields (`provider`) while adding tool-managed fields (`instructions`) — same principle as `CLAUDE.local.md` but achieved through JSON merge instead of file separation
