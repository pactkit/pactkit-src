Rule injection should be command-scoped, not global: `COMMAND_RULES_MAP` in `rules.py` maps each command to its needed rules, `_build_command_rules_header()` in `deployer.py` generates Classic @import or OpenCode inline headers; the credential safety rule (09) is force-injected via `_get_command_rules()` even when user config omits it; OpenCode inline headers must use `<!-- rules-end -->` separator instead of `---` to avoid ambiguity with YAML frontmatter `---` blocks
