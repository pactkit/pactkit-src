When a file is both pactkit-managed and user-customizable, use HTML comment markers (`<!-- pactkit:venv:start/end -->`) to partition the file into a pactkit-owned block (top) and user-owned region (below) — `_upsert_venv_managed_block()` in deployer.py replaces only the marked region via `re.sub(DOTALL)`, leaving user content untouched; this pattern allows pactkit update to persist venv paths across fresh checkouts where detection would otherwise fail
