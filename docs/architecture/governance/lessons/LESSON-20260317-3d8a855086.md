Architecture principles derived from project practice should be codified as a named rule module (08-architecture-principles.md) and deployed to all tool environments via `RULES_FILES`; the `CLAUDE_MD_TEMPLATE` auto-generate pattern (building `@import` list from `sorted(RULES_FILES.values())`) prevents new rules from being silently omitted from Classic mode while OpenCode picks them up via `instructions: ["rules/*.md"]` glob — a DRY fix exposed by adding the new module
