OpenCode `instructions: ["rules/*.md"]` glob loads ALL rules every turn (no lazy loading); the workaround is to split `RULES_FILES` into `RULES_CORE_FILES` (always-load via instructions, 3 files), `RULES_ONDEMAND_FILES` (referenced via `@rules/xxx.md` in AGENTS.md, AI reads on-demand via Read tool), and `RULES_INSTRUCTIONS_CORE` (list including user-managed files like `09-credential-safety.md`); user-managed files MUST NOT be in `RULES_FILES` (which drives `_deploy_rules`) or they cause `KeyError` in `prompts.RULES_MODULES` lookup
