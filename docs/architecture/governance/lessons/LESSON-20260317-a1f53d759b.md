OpenCode command-level model routing requires `model:` in frontmatter (not just `agent.{name}.model` in opencode.json) — `_resolve_opencode_model_id()` maps shortnames (sonnet/opus/haiku) to full `provider/model-id` by scanning `opencode.json` providers; `command_models` in pactkit.yaml enables user override; also: any config YAML comments referencing `~/.claude/` must be tool-agnostic since OpenCode users see those comments in `.opencode/pactkit.yaml`
