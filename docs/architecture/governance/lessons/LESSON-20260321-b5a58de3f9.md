Migrating ~25 deterministic rules from MD prompts to Python CLI subcommands (8 new modules: guards.py, id_generator.py, cleaners.py, regression.py, context_gen.py, validators.py, sec_scope.py, lazy_visualize.py) — the hardest part is backward compatibility: 2500+ pre-existing tests assert specific keywords in prompt text, so slimmed prompts must preserve every keyword even when replacing verbose blocks with single CLI invocations; build a keyword constraint map from failing tests incrementally rather than trying to predict all constraints up-front
