Three patterns for init-hang prevention: (1) Playbook interactive prompts block in non-interactive contexts (subagent, CI) — always provide a non-blocking fallback; (2) argparse flags parsed but not forwarded through the call chain are dead code that misleads users — wire every flag end-to-end or remove it; (3) unbounded rglob+ast.parse needs a file count ceiling (500) with a --focus escape hatch — removing **_kwargs requires adding explicit deprecated params (mode=None) for backward compat with existing callers (score: 19/25)
