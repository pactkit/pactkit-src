Tool-internal config files (pactkit.yaml) must not be hardcoded to a single tool's directory — `load_config()` multi-path lookup (`.claude/` → `.opencode/`) with `find_pactkit_yaml()` helper + env-aware `resolve_pactkit_yaml_dir()` for generation keeps the CLI tool-agnostic; skill scripts (board.py) that run standalone cannot import library modules, so must inline the path lookup logic rather than calling `from pactkit.config import find_pactkit_yaml`
