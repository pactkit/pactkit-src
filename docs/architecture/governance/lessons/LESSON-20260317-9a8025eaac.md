Prompt templates with hardcoded env paths should use named placeholders (`{BOARD_CMD}`, `{SKILLS_ROOT}` etc.) resolved at deploy time by `_render_prompt(template, profile)`; use sequential `str.replace()` over `str.format_map()` because user-facing templates contain complex keys like `{R1, R2, ...}` and `{version}_*.mmd` that cause `ValueError: Empty attribute` in Python's format parser; f-string prompt constants must be converted to plain strings first
