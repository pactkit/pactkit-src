CI pipeline generation (`_deploy_ci`) is project-level (writes `.github/workflows/`), not tool-format-level — both `_deploy_classic()` and `_deploy_opencode()` must call it; `CI_PROFILES` in `workflows.py` parallels `LANG_PROFILES` to avoid hardcoding stack-specific setup actions/images in templates; `actions_ref` prefix replacement uses string prepend (`{ref}actions/checkout@v4`) rather than regex to stay simple and YAML-injection-safe; explicit `ci.github_host` config takes priority over `_detect_ghe()` auto-detection so users without git remotes can still configure GHE mode
