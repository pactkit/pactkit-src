`(Mandatory)` labels on Phase 0 headers cause LLM extended thinking loops — the label reinforces "complete all thinking before output", combining with dense MUST requirements (7+ in Plan Phase 3) to create cognitive overload; fix has two layers: (1) remove `(Mandatory)` + add `Execution Style: incremental output` directive, (2) split monolithic phases into sub-phases (3.1/3.2/3.3) with explicit output checkpoints between steps; extends STORY-008/061 pattern of removing prompt elements that conflict with LLM native behavior
