## Context

After the CLI migration blitz (STORY-slim-014 through STORY-slim-017) and cross-flow audits (BUG-slim-003 through BUG-slim-005), a comprehensive 3-agent audit revealed 12 residual gaps across mmd graphs, documentation, board schema, and prompt cross-references.

### Root Cause Analysis

Three systemic process gaps caused the graph staleness:

1. **Lazy Visualize Protocol doesn't cover focus graphs**: Act Phase 4 and Done Phase 2 run `pactkit visualize --lazy` which regenerates `code_graph.mmd`, `class_graph.mmd`, `call_graph.mmd`. But `focus_file_graph.mmd` and `focus_call_graph.mmd` (generated by Act Phase 1 `--focus`) are never refreshed after implementation. Result: focus graphs freeze at the Phase 1 snapshot and drift as new modules are added.

2. **`pactkit visualize --lazy` is a decision-only tool, not an executor**: When `should_visualize()` returns True, `cli.py` prints "Run visualize skill for full graph generation" and exits. It does NOT actually invoke `visualize.py` to regenerate the graphs. The AI agent must manually run the skill script — but may skip or forget it.

3. **HLD consistency check is a soft "warn" with no automation**: Done Phase 2 step 3 says "Verify `system_design.mmd` component counts match reality. Warn if stale." This relies entirely on AI judgment. There is no `pactkit` subcommand or code to detect module count drift between `system_design.mmd` and actual `src/pactkit/*.py` files.

## Requirements

### R1: Fix sprint_board.md missing `In Progress` section
The `## 🔄 In Progress` section is absent from `docs/product/sprint_board.md`, violating `BOARD_SECTIONS` in `schemas.py`. This causes `board.py add_story()` to fall back to append mode. Restore the missing section between Backlog and Done.

### R2: Fix HOTFIX_PROMPT `pactkit next-id --prefix HOTFIX` broken reference
`workflows.py` HOTFIX_PROMPT Phase 0 item 4 references `pactkit next-id --prefix HOTFIX`, but `cli.py` `next-id` accepts no arguments. Remove the false `--prefix HOTFIX` claim. The HOTFIX_PROMPT MUST instruct agents to use the manual `HOTFIX-{developer}-NNN` pattern.

### R3: Make `pactkit visualize --lazy` an end-to-end executor
Currently `cli.py` `visualize --lazy` only decides whether to run, then prints a message. It MUST actually invoke `visualize.py` to regenerate all graphs when `should_visualize()` returns True. Specifically:
- Run file mode → `code_graph.mmd`
- Run class mode → `class_graph.mmd`
- Run call mode → `call_graph.mmd`
- If `focus_file_graph.mmd` exists, run focus file mode → refresh it
- If `focus_call_graph.mmd` exists, run focus call mode → refresh it

The focus target MUST be auto-detected from the existing focus graph filename (the focus module is encoded in the graph's edges — extract the most-connected node, or default to `cli`).

### R4: Add HLD module count check to `pactkit doctor`
Add a new check function `check_hld_module_count()` in `doctor.py` that:
- Counts unique `.py` module files in `src/pactkit/` (excluding `__init__.py` and `__pycache__`)
- Counts node declarations in `system_design.mmd`
- Returns `{"source_modules": N, "hld_nodes": M, "drift": N - M}` when drift > 0
- Done Phase 2 step 3 prompt MUST reference `pactkit doctor` for HLD check instead of relying on AI judgment

### R5: Fix rules.md ADR-008 table formatting
ADR-008 is outside the Markdown table due to a blank line after ADR-007. Remove the blank line so ADR-008 renders as a table row.

### R6: Fix context.md Active Branches
Regenerate `context.md` via `pactkit context` to include all local branches.

### R7: Remove dead `cleanup` key from LANG_PROFILES
The `cleanup` key is defined in all 4 LANG_PROFILES entries in `workflows.py` but never consumed directly — `cleaners.py` maintains an inline copy. Remove the dead key from LANG_PROFILES to match the SSoT pattern (cleaners.py is the canonical source).

### R8: Update system_design.mmd HLD
The hand-crafted `system_design.mmd` is missing the entire new CLI-callable module layer (18+ modules). Add a "CLI Subcommand Modules" subgraph showing the relationship between `cli.py` and the new modules. This is a one-time data fix; R4 prevents recurrence.

### R9: Update Done Phase 2 prompt to use `pactkit doctor` for HLD check
Replace the soft "Verify system_design.mmd component counts match reality. Warn if stale." with a deterministic instruction: "Run `pactkit doctor` and check HLD drift. If drift > 3, WARN user to update system_design.mmd."

### AC2: HOTFIX next-id reference fixed
- **Given**: `HOTFIX_PROMPT` from `workflows.py`
- **When**: Search for `--prefix`
