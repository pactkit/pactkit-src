# BUG-024: board.py regex requires `[ID]` brackets — rejects bare `### STORY-xxx:` titles

| Field     | Value |
|-----------|-------|
| ID        | BUG-024 |
| Status    | Draft |
| Priority  | Medium |
| Release   | 1.3.1 |
| Author    | System Architect |

## Symptom

When a story or bug title on `sprint_board.md` is written as `### STORY-041: Title` instead of `### [STORY-041] Title`, all board operations silently skip it:
- `archive_stories()` cannot split the block → story stays on board forever
- `fix_board()` / `_parse_story_blocks()` cannot extract the block → story is invisible
- `update_task()` cannot locate the story → returns "Story not found"
- `list_stories()` cannot match the header → story omitted from listing

Currently, STORY-040 and STORY-041 are stuck in the Done section of `sprint_board.md` because their titles use the bare `### STORY-xxx:` format without brackets.

## Root Cause

Four regex patterns in `src/pactkit/skills/board.py` hardcode `\[...\]` bracket syntax:

| Line | Function | Pattern | Impact |
|------|----------|---------|--------|
| 47 | `_parse_story_blocks()` | `^### \[({ITEM_ID_RE})\].*` | Cannot extract story blocks |
| 145 | `update_task()` | `### \[{sid}\].*` | Cannot locate story for task toggle |
| 192 | `list_stories()` | `^### \[({ITEM_ID_RE})\] (.+)$` | Cannot list story |
| 222 | `archive_stories()` | `(?=^### \[(?:STORY\|HOTFIX\|BUG)-)` | Cannot split block for archiving |

The canonical format `### [ID] Title` is generated by `add_story()` (L30), but LLM agents and human editors often write the natural Markdown form `### STORY-xxx: Title` or `### STORY-xxx Title`.

## Target Call Chain

```
board.py CLI → archive_stories()
                → re.split(r'(?=^### \[(?:STORY|HOTFIX|BUG)-)', ...)  ← BUG: misses bare titles
                → per-block has_done/has_todo check
                → write archive file + rewrite board

board.py CLI → _parse_story_blocks()
                → re.finditer(r'^### \[({ITEM_ID_RE})\].*', ...)     ← BUG: misses bare titles
                → _classify_story() per block
                → rebuild board sections

board.py CLI → update_task()
                → re.search(r'### \[{sid}\].*', ...)                   ← BUG: misses bare titles
                → toggle task checkbox
                → fix_board()

board.py CLI → list_stories()
                → re.finditer(r'^### \[({ITEM_ID_RE})\] (.+)$', ...)  ← BUG: misses bare titles
                → count done/todo per block
```

## Requirements

### R1: Flexible title pattern (MUST)

All four regex patterns MUST accept both formats:
- Bracketed: `### [STORY-041] Title text`
- Bare: `### STORY-041: Title text`
- Bare without colon: `### STORY-041 Title text`

Define a single shared title pattern constant (e.g., `TITLE_RE`) to avoid duplication.

Recommended pattern skeleton:
```
^### (?:\[({ITEM_ID_RE})\]|({ITEM_ID_RE}):?)\s+(.+)
```

### R2: Normalize on extraction (SHOULD)

When extracting the story ID, the result MUST be the same regardless of input format. For example, both `### [STORY-041] Foo` and `### STORY-041: Foo` should extract `STORY-041`.

### R3: add_story canonical format preserved (MUST)

`add_story()` MUST continue to generate the canonical `### [{sid}] {title}` format. The fix is read-side tolerance, not write-side change.

### R4: Existing board cleanup (SHOULD)

After the code fix, run `archive_stories()` or `fix_board()` to process the currently-stuck STORY-040 and STORY-041 entries in `sprint_board.md`.

## Acceptance Criteria

### AC1: Bare title archiving
**Given** a board with `### STORY-099: Completed Feature` and all tasks `[x]`
**When** `archive_stories()` is called
**Then** the story is archived to `docs/product/archive/`
**And** removed from the board

### AC2: Bare title listing
**Given** a board with `### BUG-050: Fix something` in Backlog
**When** `list_stories()` is called
**Then** output includes `BUG-050 | Fix something | 0/N | BACKLOG`

### AC3: Bare title task update
**Given** a board with `### HOTFIX-010: Urgent fix` and task `- [ ] Patch it`
**When** `update_task('HOTFIX-010', ['Patch', 'it'])` is called
**Then** the task is toggled to `[x]`

### AC4: Bare title fix_board
**Given** a board with `### STORY-099: Title` in Backlog but all tasks `[x]`
**When** `fix_board()` is called
**Then** the story is moved to the Done section

### AC5: Bracketed format still works
**Given** a board with `### [STORY-100] Normal title` and all tasks `[x]`
**When** `archive_stories()` is called
**Then** behavior is identical to current (no regression)

### AC6: add_story still writes brackets
**Given** a call to `add_story('STORY-101', 'New feature', 'Task A|Task B')`
**When** the board is written
**Then** the entry is `### [STORY-101] New feature`
