# Spec BUG-004: deployer.py dead set() call in _deploy_rules
- **Release**: 1.1.2

## Context
In `_deploy_rules()`, line 279 calls `set(enabled_rules)` but discards the result. This is dead code left from a refactor — the function works correctly without it because it iterates `enabled_rules` directly via the reverse map.

## Requirements
- The system MUST remove the dead `set(enabled_rules)` line from `_deploy_rules()`.
- The system MUST NOT change any functional behavior of `_deploy_rules()`.

## Acceptance Criteria

### Scenario 1: Dead code removed
- **Given** the source code of `_deploy_rules()` in `deployer.py`
- **When** the function is inspected
- **Then** there is no standalone `set(enabled_rules)` expression

### Scenario 2: Deployment still works
- **Given** a valid config with enabled rules
- **When** `_deploy_rules()` is called
- **Then** only the enabled rules are deployed (existing behavior preserved)

## Design
Delete the single line `set(enabled_rules)`. Fix the misleading comment on line 281.

## Target Call Chain
`deploy()` → `_deploy_classic()` → `_deploy_rules()`
