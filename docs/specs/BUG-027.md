# Spec BUG-027: Sprint Board Story 标题级别不一致导致归档失败

| Field | Value |
|-------|-------|
| ID | BUG-027 |
| Priority | Medium |
| Release | 1.6.1 |
| Status | Draft |
| Author | System Architect |

## Background

当用户执行 `/project-init` 创建 `sprint_board.md` 时，由于 Phase 4 没有提供标准模板，AI 可能生成 `####`（四级标题）而不是 `###`（三级标题）。后续的 `archive_stories` 函数使用硬编码的 `### ` 正则匹配，无法识别 `####` 标题的 Story，导致归档失败。

## Requirements

### R1: scaffold.py 提供 create_board 函数
`scaffold.py` MUST 提供 `create_board()` 函数，生成标准格式的 `sprint_board.md`。

### R2: project-init 使用 scaffold 命令
`/project-init` Phase 4 MUST 使用 `scaffold.py create_board` 命令创建 board。

### R3: 正则容错匹配
`board.py` 中的正则表达式 SHOULD 同时匹配 `###` 和 `####` 标题（向后兼容旧格式）。

### R4: add_story 保持标准格式
`add_story` 函数 MUST 继续生成 `###` 格式（保持规范）。

## Acceptance Criteria

### Scenario 1: 新项目初始化创建标准 Board

- **Given** 项目没有 `docs/product/sprint_board.md`
- **When** 执行 `/project-init`
- **Then** 使用 `scaffold.py create_board` 创建标准格式的 board
- **Then** Board 包含 `## 📋 Backlog`、`## 🔄 In Progress`、`## ✅ Done` 三个 section

### Scenario 2: 归档可识别 #### 格式的旧 Story

- **Given** `sprint_board.md` 中存在 `#### [STORY-001]` 格式的旧 Story
- **When** 执行 `archive_stories`
- **Then** 归档逻辑能正确识别并归档该 Story

### Scenario 3: add_story 保持标准格式

- **Given** 使用 `add_story` 添加新 Story
- **When** Story 被添加到 board
- **Then** Story 标题使用 `### [ID]` 格式（三级标题）

## Design

### 修改文件

| File | Change |
|------|--------|
| `src/pactkit/skills/scaffold.py` | 添加 `create_board()` 函数 |
| `src/pactkit/skills/board.py` | 修改正则以同时匹配 `###` 和 `####` |
| `src/pactkit/prompts/commands.py` | 修改 `/project-init` Phase 4 使用 scaffold 命令 |

### create_board() 模板

```markdown
# Sprint Board

## 📋 Backlog


## 🔄 In Progress


## ✅ Done

```

### 正则修改

```python
# Before
_TITLE_RE = rf'^### \[?({ITEM_ID_RE})\]?:?\s*(.*)'

# After (容错匹配 ### 和 ####)
_TITLE_RE = rf'^#{3,4} \[?({ITEM_ID_RE})\]?:?\s*(.*)'
```

## Target Call Chain

```
/project-init Phase 4
    └── scaffold.py create_board
            └── write docs/product/sprint_board.md (标准模板)

archive_stories()
    └── re.split(r'(?=^#{3,4} \[?...)')  # 容错匹配
            └── 识别 ### 和 #### 标题

add_story()
    └── f'### [{sid}] {title}'  # 保持标准格式
```
