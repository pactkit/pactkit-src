# BUG-020: Project CLAUDE.md generation skips venv when file exists — should backup and regenerate

| Field     | Value |
|-----------|-------|
| Status    | Open |
| Author    | System Architect |
| Release   | 1.3.2 |

## Context

BUG-019 implemented `_generate_project_claude_md_if_missing()` with a "skip if exists" strategy:

```python
if claude_md_path.exists():
    return
```

**Problem**: For projects with existing `.claude/CLAUDE.md`, venv is never configured because the function exits early. Users must manually add the venv section.

**User Expectation**: Running `pactkit init` should always ensure venv is configured when detected, regardless of whether CLAUDE.md exists.

## Target Call Chain

```
deployer.py:_generate_project_claude_md_if_missing()
  → if claude_md_path.exists():
      → shutil.copy(claude_md_path, claude_md_path.with_suffix('.md.bak'))  # NEW
      → print("  -> Backed up CLAUDE.md to CLAUDE.md.bak")  # NEW
  → (continue with venv detection and generation)
```

## Requirements

### R1: Backup Existing File
- IF `.claude/CLAUDE.md` exists, the function MUST create a backup at `.claude/CLAUDE.md.bak`.
- The backup MUST preserve the original file content exactly.
- IF `.claude/CLAUDE.md.bak` already exists, it MUST be overwritten (only keep most recent backup).

### R2: Always Generate Fresh CLAUDE.md
- After backup (if needed), the function MUST generate a fresh CLAUDE.md with venv section (when detected).
- The generation logic MUST remain unchanged from BUG-019.

### R3: User Notification
- IF a backup was created, print: "  -> Backed up CLAUDE.md to CLAUDE.md.bak"
- The message MUST appear in the deployment output to inform users.

### R4: Backward Compatibility
- Projects without existing CLAUDE.md MUST behave as before (generate new file).
- Backup is only created when an existing file is found.

## Acceptance Criteria

### AC1: Existing File Backed Up
- **Given** `.claude/CLAUDE.md` exists with custom content
- **And** `.venv/bin/python3` exists
- **When** `pactkit init` is run
- **Then** `.claude/CLAUDE.md.bak` is created with the original content
- **And** `.claude/CLAUDE.md` contains the venv section

### AC2: Fresh Project Unchanged
- **Given** `.claude/CLAUDE.md` does NOT exist
- **When** `pactkit init` is run
- **Then** no `.bak` file is created
- **And** `.claude/CLAUDE.md` is generated normally

### AC3: Backup Overwrites Previous Backup
- **Given** `.claude/CLAUDE.md.bak` already exists
- **When** `pactkit init` is run with existing CLAUDE.md
- **Then** `.claude/CLAUDE.md.bak` is overwritten with new backup

### AC4: Notification Printed
- **Given** existing `.claude/CLAUDE.md`
- **When** `pactkit init` is run
- **Then** output includes "Backed up CLAUDE.md to CLAUDE.md.bak"
