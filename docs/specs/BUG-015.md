# BUG-015: PactKit CI workflow fails due to missing `pactkit init` step

- **Release**: 1.3.0
- **Priority**: Medium
- **Type**: CI Fix

## Problem

The project has two CI workflows that both trigger on `push` to `main`:

| Workflow | File | `pactkit init` | Status |
|----------|------|----------------|--------|
| CI | `.github/workflows/ci.yml` | Yes (line 29) | Passes |
| PactKit CI | `.github/workflows/pactkit.yml` | No | **Fails** |

`pactkit.yml` runs `pytest tests/ -v` without first running `pactkit init`, so tests that read deployed files from `~/.claude/` fail with `FileNotFoundError`:

- `test_agent_frontmatter.py` — 3 failures (reads `~/.claude/agents/*.md`)
- `test_command_visualize_modes.py` — 8 failures (reads `~/.claude/commands/*.md` and `~/.claude/agents/*.md`)

Total: **11 test failures** on every push to `main`.

### Root Cause

`pactkit.yml` was added as a secondary CI workflow but lacks the `pactkit init` step that `ci.yml` includes. The two workflows are redundant — `ci.yml` already covers Python 3.10/3.11/3.12/3.13 with full test suite.

## Requirements

- MUST remove `.github/workflows/pactkit.yml` — it is a strict subset of `ci.yml` (single Python 3.11, same lint + test steps, but missing `pactkit init`)
- MUST verify that `ci.yml` continues to pass after removal
- MUST NOT modify `ci.yml`
- MUST NOT modify any test files

## Acceptance Criteria

### AC1: Redundant workflow removed
- **Given** `.github/workflows/pactkit.yml` exists
- **When** the fix is applied
- **Then** the file is deleted and only `ci.yml` remains

### AC2: Main CI still passes
- **Given** `ci.yml` runs on push to `main`
- **When** tests are executed
- **Then** all tests pass (including the 11 that previously failed in `pactkit.yml`)

### AC3: No orphan workflow on GitHub Actions
- **Given** the workflow file is deleted
- **When** the next push triggers CI
- **Then** only the "CI" workflow appears in GitHub Actions (no "PactKit CI")

## Target Call Chain

Files to modify:
- `.github/workflows/pactkit.yml` — DELETE
