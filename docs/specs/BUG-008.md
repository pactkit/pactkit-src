# BUG-008: Stale demoted-command references in agent and skill prompts

- **Type**: Bug
- **Priority**: High
- **Release**: 1.2.0
- **Root Cause**: STORY-011 demoted 6 commands to embedded skills, BUG-007 fixed `/project-trace` references but missed the remaining 4 demoted commands (`project-review`, `project-release`, `project-doctor`, `project-draw`)

## Problem

Agent prompts in `agents.py` instruct the LLM to "read `commands/project-{name}.md`" for 4 agents, but these command files no longer exist — they were demoted to embedded skills in STORY-011. Skill SKILL.md templates in `skills.py` also reference `/project-doctor` and `/project-release` as standalone commands.

When deployed, agents will attempt to read non-existent files, causing silent failures or confused LLM behavior.

## Affected References

### agents.py (4 stale references)
| Line | Agent | Stale Reference | Correct |
|------|-------|----------------|---------|
| 103 | qa-engineer | `commands/project-review.md` | `pactkit-review` skill |
| 140 | repo-maintainer | `commands/project-release.md` | `pactkit-release` skill |
| 173 | system-medic | `commands/project-doctor.md` | `pactkit-doctor` skill |
| 245 | visual-architect | `commands/project-draw.md` | `pactkit-draw` skill |

### skills.py (3 stale references)
| Line | Skill Template | Stale Reference | Correct |
|------|---------------|----------------|---------|
| 73 | SKILL_VISUALIZE_MD | `/project-doctor` | `pactkit-doctor` skill |
| 147 | SKILL_BOARD_MD | `/project-release` | `pactkit-release` skill |
| 148 | SKILL_BOARD_MD | `/project-doctor` | `pactkit-doctor` skill |

## Requirements

1. Agent prompts MUST NOT reference `commands/project-{name}.md` for demoted commands
2. Agent prompts MUST reference the correct embedded skill name instead
3. Skill SKILL.md templates MUST NOT reference demoted commands as `/project-{name}`
4. Skill SKILL.md templates MUST reference the correct skill name instead
5. All existing tests MUST continue to pass

## Acceptance Criteria

### AC1: Agent prompt stale references removed
- **Given** the qa-engineer, repo-maintainer, system-medic, and visual-architect agent prompts
- **When** deployed to any format (classic/plugin/marketplace)
- **Then** none reference `commands/project-review.md`, `commands/project-release.md`, `commands/project-doctor.md`, or `commands/project-draw.md`

### AC2: Agent prompts reference correct skills
- **Given** the 4 affected agent prompts
- **When** inspected at source level
- **Then** each references the correct embedded skill name (`pactkit-review`, `pactkit-release`, `pactkit-doctor`, `pactkit-draw`)

### AC3: Skill template stale references removed
- **Given** SKILL_VISUALIZE_MD and SKILL_BOARD_MD templates
- **When** inspected at source level
- **Then** no references to `/project-doctor` or `/project-release` as standalone commands

### AC4: Skill templates reference correct skills
- **Given** the affected skill templates
- **When** inspected at source level
- **Then** each references the correct skill name (`pactkit-doctor`, `pactkit-release`)
