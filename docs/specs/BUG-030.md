# BUG-030: Spec Linter Path Not Found in External Projects

| Field | Value |
|-------|-------|
| ID | BUG-030 |
| Status | Draft |
| Priority | High |
| Release | 1.6.7 |

## Background

When using PactKit in external projects (not the pactkit development repository), the Plan and Sprint commands fail with "No such file or directory" error when trying to run the spec linter:

```
/opt/homebrew/Cellar/python@3.12/3.12.12/Frameworks/Python.framework/Versions/3.12/Resources/Python.app/Contents/MacOS/Python: can't open file
'/Users/slim/workspaces/mhigh/src/pactkit/skills/spec_linter.py': [Errno 2] No such file or directory
```

The problem is that prompts in `commands.py` and `workflows.py` use a hardcoded relative path `python3 src/pactkit/skills/spec_linter.py` which only exists within the pactkit development repository.

## Target Call Chain

```
User runs /project-plan in external project
  → prompts/commands.py (PLAN_PROMPT, line ~122, ~154)
  → prompts/workflows.py (line ~681)
  → Bash: python3 src/pactkit/skills/spec_linter.py docs/specs/{ID}.md
  → FAIL: path does not exist in external projects
```

## Requirements

### R1: Add `pactkit spec-lint` CLI Subcommand
The CLI (`cli.py`) MUST expose a `spec-lint` subcommand that invokes `spec_linter.validate_spec()` and prints formatted results.

### R2: Update Prompt References
All prompt templates MUST replace the hardcoded path `python3 src/pactkit/skills/spec_linter.py` with `pactkit spec-lint`.

### R3: Backward Compatibility
The CLI subcommand MUST support the same arguments as the standalone script:
- `pactkit spec-lint <spec_path>` — validate a single spec
- `pactkit spec-lint --all` — validate all specs in `docs/specs/`
- `pactkit spec-lint --all --specs-dir <path>` — validate all specs in custom directory

## Out of Scope

- Modifying the `spec_linter.py` validation logic itself
- Removing the standalone script capability (it should still work when run directly within pactkit repo)

## Acceptance Criteria

**Given** PactKit is installed

### AC2: CLI spec-lint --all works
