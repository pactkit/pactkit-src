## Background

PactKit visualize 生成的 `.mmd` Mermaid 文件需要额外工具才能查看，对企业用户不友好。参考 CodeFlow 项目（单文件 HTML + D3 力导向图 + 纯前端渲染）的思路，创建一个独立的 `pactkit-report` skill，将 `.mmd` 文件转换为交互式 D3 力导向图 HTML。

**设计决策**：
1. **独立 skill** — 不修改现有 PDCA skill（visualize/board/scaffold 等），独立演进
2. **D3 力导向图** — 比 Mermaid 渲染更适合大图（支持拖拽、物理模拟、节点聚类）
3. **解析 .mmd 输入** — 将 Mermaid `graph TD` 语法解析为节点+边 JSON，喂给 D3
4. **单文件 HTML** — 内嵌 D3 CDN + 解析器 + 渲染器，浏览器直接打开
5. **可选集成 STORY-slim-089** — blast radius 高亮、complexity 热力图、layer 着色作为可视化增强层

## Requirements

### R1: Mermaid Parser (MUST)

实现 `.mmd` 文件解析器，提取节点和边：
- 支持 `graph TD` / `graph LR` 格式的 file/call/module 图
- 支持 `classDiagram` 格式的 class 图
- 支持 `subgraph ... end` 分组（映射为 D3 node group）
- 解析节点 ID、标签（从 `nodeId["label"]` 语法中提取）
- 解析边关系（`-->`, `-.->`, `-->|label|`）
- 解析 `click nodeId href "path"` 行为文件路径元数据
- 解析 `linkStyle N stroke:red` 为边样式（layer violation 红色标注）
- 输出：`{nodes: [{id, label, group?, href?}], edges: [{source, target, label?, style?}]}`

### R2: D3 Force-Directed Graph Renderer (MUST)

单文件 HTML 模板，内嵌 D3.js（CDN `https://cdn.jsdelivr.net/npm/d3@7`）：
- **力模拟**: charge repulsion + link distance + center gravity
- **节点渲染**: 圆形节点 + 文本标签，大小按连接数缩放
- **边渲染**: 有向箭头，标签可选显示
- **分组**: subgraph 节点同色聚类（convex hull 或背景色）
- **响应式**: 自动适应窗口大小

### R3: Interactive Features (MUST)

- **Zoom**: 鼠标滚轮缩放 + 双击重置
- **Pan**: 拖拽画布平移
- **Drag**: 拖拽单个节点重新布局
- **Hover**: 悬停节点时高亮其直接依赖（入边+出边），淡化其他节点
- **Click**: 点击节点显示详情面板（文件路径、连接数、所属分组）

### R4: Node Search (MUST)

- 顶部搜索框，实时过滤
- 输入文件名或函数名，匹配的节点高亮闪烁
- 非匹配节点淡化（opacity 降低）
- 显示匹配数量（"3 of 42 nodes"）
- ESC 或清空搜索框恢复全部显示

### R5: Theme Toggle (MUST)

- 暗色/亮色模式切换按钮
- 暗色：深色背景 + 亮色节点/边
- 亮色：白色背景 + 深色节点/边
- 偏好通过 `localStorage` 持久化

### R6: Report Metadata (MUST)

HTML 包含：
- 标题：`{project_name} — {mode} Graph`
- 生成时间戳
- 页脚：`Generated by PactKit {version}`
- 节点数 / 边数统计

### R7: Skill Entry Point (MUST)

创建 `pactkit-report` skill，入口脚本 `report.py`：
- `report.py generate --input <mmd_file>` → 生成同名 `.html`
- `report.py generate --all` → 转换 `docs/architecture/graphs/*.mmd` 全部文件
- `report.py generate --input <mmd_file> --output <html_file>` → 指定输出路径
- 作为 PactKit skill 部署，可在 Claude Code / OpenCode 等环境中调用

### R8: STORY-slim-089 Integration Layer (SHOULD)

可选增强层，当数据可用时自动集成：
- **Blast radius 高亮**: 如果 blast_radius JSON 数据传入，受影响节点用橙色圈标记
- **Complexity 热力图**: 如果 complexity JSON 数据传入，节点颜色按复杂度从绿→黄→红渐变
- **Layer 着色**: 如果 layer 分类数据传入，节点按 layer 着色 + violation 边标红
- 通过 `--overlay` 参数传入增强数据：`report.py generate --input code_graph.mmd --overlay blast_radius.json`

## Acceptance Criteria

### AC1: Basic MMD to HTML (R1, R2)

- **Given** an existing `code_graph.mmd` with `graph TD` and 10+ nodes
- **When** `report.py generate --input code_graph.mmd`
- **Then** `code_graph.html` is created; opening in browser shows a D3 force-directed graph with all nodes and edges

### AC2: Subgraph Grouping (R1, R2)

- **Given** a `workflow_graph.mmd` with subgraph sections (Commands, Agents, Skills)
- **When** `report.py generate --input workflow_graph.mmd`
- **Then** nodes in the same subgraph share the same color group

### AC3: Zoom, Pan, Drag (R3)

- **Given** a rendered HTML report
- **When** the user scrolls, drags background, or drags a node
- **Then** the view zooms, pans, or the node repositions with force simulation adjustment

### AC4: Hover Highlights Dependencies (R3)

- **Given** a rendered HTML report with node A→B→C
- **When** the user hovers over node B
- **Then** A and C are highlighted (direct neighbors), other nodes fade

### AC5: Node Search (R4)

- **Given** a rendered HTML report with 20+ nodes
- **When** the user types "service" in the search box
- **Then** all nodes containing "service" highlight; others fade; count shows "N of M nodes"

### AC6: Dark/Light Theme (R5)

- **Given** a rendered HTML report
- **When** the user clicks the theme toggle
- **Then** colors switch between dark and light; preference persists on reload

### AC7: Generate All (R7)

- **Given** 3 `.mmd` files in `docs/architecture/graphs/`
- **When** `report.py generate --all`
- **Then** 3 corresponding `.html` files are created

### AC8: classDiagram Support (R1)

- **Given** a `class_graph.mmd` with `classDiagram` syntax
- **When** `report.py generate --input class_graph.mmd`
- **Then** classes are rendered as rectangular nodes with method lists; inheritance edges use dashed arrows

### AC9: Report Metadata (R6)

- **Given** a generated HTML report
- **When** the user opens it in a browser
- **Then** the page shows: project title, mode name, generation timestamp, node/edge count, and "Generated by PactKit {version}" footer

### AC10: Complexity Overlay (R8)

- **Given** a `code_graph.mmd` and a complexity JSON from `visualize.py complexity --format json`
- **When** `report.py generate --input code_graph.mmd --overlay complexity.json`
- **Then** nodes are colored by complexity (green→yellow→red gradient)

