# BUG-011: Stale command references in agent and skill prompt templates

- **Type**: Bug
- **Priority**: High
- **Release**: 1.2.0
- **Discovered**: 360-degree code audit (second pass)

## Context

In v1.2.0, six commands were demoted to skills (STORY-011). BUG-007 and BUG-008 fixed stale references in some prompt templates, but 7 references were missed:

- `agents.py`: 4 stale references in agent protocol section headers
- `workflows.py`: 3 stale `Usage:` lines in skill prompt templates

## Root Cause

BUG-008 scanned for stale references but did not cover agent protocol sub-headers or skill prompt `Usage:` lines. The agent prompts describe skill protocols using the old `/project-*` command syntax, and the skill prompt templates have `Usage:` lines showing `/project-*` instead of the skill invocation pattern.

## Target Call Chain

```
deployer._deploy_agents() → prompts.AGENTS[key]["prompt"] → written to disk
deployer._deploy_skills() → prompts.SKILL_*_MD → written to disk via SKILL.md
```

No runtime code changes needed — all fixes are prompt string edits.

## Requirements

1. **MUST** update `agents.py` to replace stale `/project-*` references in protocol section headers:
   - Line 98: `### /project-review (PR Code Review)` → skill-aware phrasing
   - Line 135: `### /project-release (Version Release)` → skill-aware phrasing
   - Line 167: `## Protocol (/project-doctor)` → skill-aware phrasing
   - Line 238: `## Protocol (/project-draw)` → skill-aware phrasing

2. **MUST** update `workflows.py` to replace stale `Usage:` lines in skill prompt templates:
   - Line 13: `- **Usage**: \`/project-trace "$ARGUMENTS"\`` → correct skill invocation
   - Line 176: `- **Usage**: \`/project-draw "$ARGUMENTS"\`` → correct skill invocation
   - Line 426: `- **Usage**: \`/project-review "$ARGUMENTS"\`` → correct skill invocation

3. **MUST** verify zero remaining stale references via: `grep -r '/project-(trace|draw|status|doctor|review|release)' src/pactkit/prompts/`

## Acceptance Criteria

### AC1: Agent prompt stale references removed
- **Given** `agents.py` agent definitions
- **When** deployed via `pactkit init`
- **Then** no deployed agent `.md` file contains `/project-review`, `/project-release`, `/project-doctor`, or `/project-draw` as command invocations

### AC2: Skill prompt Usage lines corrected
- **Given** `workflows.py` skill prompt templates
- **When** deployed via `pactkit init`
- **Then** no deployed skill `SKILL.md` contains `/project-trace`, `/project-draw`, or `/project-review` as usage syntax

### AC3: Zero stale references in source
- **Given** the `src/pactkit/prompts/` directory
- **When** grepping for `/project-(trace|draw|status|doctor|review|release)`
- **Then** zero matches are returned
