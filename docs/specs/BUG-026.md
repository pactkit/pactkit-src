## Background

When a user upgrades PactKit and runs `pactkit init` or `pactkit update`, the version numbers in `pactkit.yaml` and `context.md` are not synchronized to the current installed PactKit version.

**Current Behavior**:
- `_rewrite_yaml()` preserves the old version from user's yaml file (`data.get("version", "0.0.1")`)
- `context.md` version is manually filled by playbook, not auto-synced

**Expected Behavior**:
- `pactkit.yaml` version MUST be updated to match `__version__` on every init/update
- `context.md` version SHOULD be updated to match `pactkit.yaml` version

## Target Call Chain

```
cli.py:main()
    └── deployer.py:deploy()
        └── deployer.py:_deploy_classic()
            └── config.py:auto_merge_config_file()
                └── config.py:_rewrite_yaml()  ← Bug location
```

## Requirements

### R1: Import __version__ in config.py
**[MUST]** Import `__version__` from `pactkit` package in `config.py`.

### R2: Update version field in _rewrite_yaml
**[MUST]** `config.py:_rewrite_yaml()` MUST update the `version` field to match `pactkit.__version__` instead of preserving the old value from user's yaml.

### R3: Automatic version sync
**[SHOULD]** The version sync SHOULD occur automatically during `auto_merge_config_file()` or `_rewrite_yaml()` without requiring additional user action.

### R4: Context.md version consistency
**[MAY]** `context.md` version field MAY be updated by playbook template to read from `pactkit.yaml` for consistency.

## Acceptance Criteria

### AC1: Version updated on init
**Given** a project with pactkit.yaml version "1.4.0" and PactKit __version__ is "1.5.0"
**When** user runs `pactkit init`
**Then** pactkit.yaml version should be updated to "1.5.0"

### AC2: Version updated on update
**Given** a project with pactkit.yaml version "1.3.0" and PactKit __version__ is "1.5.0"
**When** user runs `pactkit update`
**Then** pactkit.yaml version should be updated to "1.5.0"

### AC3: Fresh init uses current version
**Given** no pactkit.yaml exists and PactKit __version__ is "1.5.0"
**When** user runs `pactkit init`
**Then** generated pactkit.yaml version should be "1.5.0"
