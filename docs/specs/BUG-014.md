# BUG-014: Stale version numbers in Spec Release fields, prompt templates, and CHANGELOG

- **Release**: 1.3.0
- **Priority**: Low
- **Type**: Housekeeping

## Problem

Version numbers across the project are inconsistent:

### A. Spec Release fields (23 files)
1. **6 specs say `1.1.5`** (STORY-019~024) — version 1.1.5 was never released; these shipped in 1.2.0
2. **4 specs say `1.2.1`** (BUG-006, BUG-007, STORY-031, STORY-032) — version 1.2.1 was never released; these shipped in 1.2.0
3. **13 specs say `TBD`** — all completed stories that should be backfilled with their actual release version

### B. Prompt template internal version labels (14 occurrences)
Commands, skills, and rules in `src/pactkit/prompts/` carry inconsistent internal iteration versions (v16.2, v18.6, v19.5, v19.8, v22.0, v23.0) that do not correspond to any PactKit release. These should be unified to the current PactKit version `v1.2.0`.

| File | Current Label | Location |
|------|--------------|----------|
| `prompts/commands.py` | Plan (v19.5), Act (v22.0), Check (v22.0), Done (v19.8), Init (v18.6) | Command headers |
| `prompts/workflows.py` | Trace (v16.2), Draw (v22.0), Sprint (v22.0), Review (v22.0), Hotfix (v22.0), Design (v22.0) | Skill/command headers |
| `prompts/rules.py` | Constitution (v23.0 Modular) | CLAUDE_MD_TEMPLATE header |
| `skills/visualize.py` | FILE (v19.7), VISUALIZE (v20.0) | Code section comments |

### C. CHANGELOG
Missing entries for BUG-010, BUG-011, BUG-012, BUG-013 in the [1.2.0] section.

## Requirements

- MUST update all spec `Release` fields to match the actual release version they shipped in
- MUST unify all prompt template version labels to `v1.2.0`
- MUST unify `skills/visualize.py` section comment versions to `v1.2.0`
- MUST add BUG-010 through BUG-013 entries to the CHANGELOG `[1.2.0]` Fixed section
- MUST NOT modify any spec content other than the `Release` metadata field
- MUST NOT change example version strings (e.g., `update_version 1.0.0` in board skill docs)
- MUST NOT change Draw.io XML `version="26.2.2"` (that is the Draw.io app version, not PactKit)
- MUST NOT change the Sprint comparison table (`vs v21.0`) — that is historical context
- SHOULD verify all specs have a non-TBD Release value after the fix
