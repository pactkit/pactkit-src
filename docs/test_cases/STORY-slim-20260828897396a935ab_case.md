# Test Cases: STORY-slim-20260828897396a935ab — Hook coverage expansion

## TC-1: SessionStart 注入与降级 (R1, AC1)

**Given** 有 board stories 与 git 仓库的已部署项目
**When** `pactkit gate --hook session-start` 运行
**Then** stdout 含再生的 context（Sprint Status / Current Stories 段），exit 0
**And** 生成失败时输出一行 WARN 且 exit 0（注入是辅助，不是门）

## TC-2: PreCompact 刷新不阻塞 (R2, AC2)

**Given** 有 workflow 状态的项目
**When** `pactkit gate --hook pre-compact` 运行
**Then** `.pactkit/context.md` 被刷新，exit 0
**And** 内部失败时 exit 仍为 0——任何代码路径都不得阻塞压缩

## TC-3: Act 期 Spec 防篡改 (R3, AC3)

**Given** 存在 active preflight receipt 的 spec（`.pactkit/preflight/{story}/current.json`）
**When** Edit 工具调用指向 `docs/specs/{story}.md`
**Then** hook exit 2，消息含 "Spec is Law"，写入 `spec_guard` 记录
**And** `PACTKIT_ALLOW_SPEC_EDIT=1` 或有效 `spec_edit` token 时放行
**And** 无 receipt 的 spec（Plan 期新 story）放行——合法写作不受影响
**And** bash 写向 receipt 绑定的 spec（`sed -i docs/specs/X.md`）同样被拦

## TC-4: 外发命令门 + TTL 凭证 (R4, AC4)

**Given** 默认 enforcement 配置
**When** hook 收到 `gh release create v1.0.0` / `gh pr create` / `npm publish` / `docker push` / `twine upload`
**Then** exit 2，消息指明 ask-first 与 `pactkit gate authorize`，写 `auth_gate` 记录
**And** 只读变体（`gh pr view`、`gh release list`、`gh repo view`、`docker pull`）exit 0 且无记录
**And** 新鲜 token 放行并记录；过期/错误 scope 的 token 再次拦截
**And** `PACTKIT_AUTHORIZED=1` 人工通道放行；`enforcement.auth_gate: false` 时整体旁路

## TC-5: 明文凭据拦截 (R5, AC5)

**Given** 默认 enforcement 配置
**When** 命令含 `AKIA…` / `password=Test@1234` / `-----BEGIN … PRIVATE KEY-----` / `glpat-…` / `sk-…` / `xoxb-…`
**Then** exit 2，写 `secrets_gate` 记录
**And** `PACTKIT_ALLOW_SECRET=1` 放行；`password=$DB_PASS`（env 间接）放行
**And** 干净命令（`ls -la && git status`）exit 0

## TC-6: 注册/配置/doctor (R6, AC6)

**Given** `pactkit init --format all` 于新项目
**When** 部署完成
**Then** `.claude/settings.json` 含 SessionStart 与 PreCompact 注册（幂等重装不重复），`.codex/hooks.json` 不含 session 事件（不可移植）
**And** `GATES`/`_PROBES` 含 `spec_guard`/`auth_gate`/`secrets_gate`，probe 在 flag 关闭时报 UNAVAILABLE 及原因
**And** `_enforcement_settings` 缺配置时回退安全默认（四新键 = true/true/true/30）
**And** validator 拒绝非正整数的 `auth_ttl_minutes`，接受全部新键
